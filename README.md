# Dasturlash asoslari

**Iqtisodiyot, Menejment va Yurisprudensiya** yo‘nalishlari talabalari uchun **Dasturlash asoslari** (Python va ma’lumotlar bazalari) fani bo‘yicha interaktiv oflayn HTML prezentatsiyalar va amaliy dasturiy loyihalar to‘plami.

## Darslar ro‘yxati

| Dars | Mavzu | Papka | Onlayn ko‘rish (GitHub Pages) |
| --- | --- | --- | --- |
| **11-dars** | Ma’lumotlar bazasi va relyatsion model asoslari (SQLite + Python `sqlite3`) | [`11-dars/`](./11-dars/) | [Prezentatsiyani ochish](https://s404ruz.github.io/dasturlash-asoslari/11-dars/) |

## Lokal kompyuterda ishga tushirish

1. Repozitoriyni yuklab oling yoki klonlang:
   ```bash
   git clone https://github.com/s404ruz/dasturlash-asoslari.git
   ```
2. Kerakli dars papkasidagi `index.html` faylini istalgan zamonaviy brauzerda (Chrome, Edge, Firefox) oching — barcha prezentatsiyalar **100% oflayn** ishlaydi.
3. Amaliy Python fayllarini ishga tushirish uchun Python 3.10+ kifoya (faqat standart kutubxonalar ishlatilgan).
